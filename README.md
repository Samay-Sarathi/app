## About the Project

**Samya Sarthi** is a Flutter-based mobile application focused on improving access to emergency healthcare through technology.

The project aims to bridge gaps in emergency healthcare coordination and create a more connected experience for patients and healthcare providers.

## Built With

- **Flutter** — Cross-platform application development
- **Dart** — Application programming language

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- An Android/iOS emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd samya-sarthi
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
